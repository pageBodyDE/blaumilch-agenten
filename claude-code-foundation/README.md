# Claude Code Foundation: der kostenlose Einsteiger-Kurs

Du benutzt jeden Tag KI und kommst trotzdem nicht aus dem Chatfenster? Das nenne ich die Chat-Decke: das Chatfenster vergisst dich nach jedem Gespräch, kommt an deine Dateien nicht heran, gibt dir Text und hört dann auf. Was dich vom Bauen trennt, ist kein fehlendes Können, sondern ein fehlender begleiteter Weg. Den gibt es hier, komplett kostenlos: fünf Module von der ersten Minute bis zum ersten eigenen Werkzeug, ohne eine Zeile Code.

**Zur ganzen Ausgabe auf Substack:** https://blaumilch.substack.com/p/die-chat-decke

## Die fünf Module

1. **Setup & Unabhängigkeit.** Du richtest Claude Code selbst ein, in einem neutralen, kostenlosen Editor, und behältst von der ersten Minute an das Steuer. [→ ansehen](https://blaumilch.substack.com/p/die-chat-decke)
2. **Clever arbeiten.** Kontext im Griff, Plan-Modus vor jedem Schritt, sicher bleiben, ganz ohne Entwickler zu sein. [→ ansehen](https://blaumilch.substack.com/p/die-chat-decke)
3. **Deine erste Skill.** Dein erstes eigenes Werkzeug, komplett im Gespräch, für eine Aufgabe, die du sonst jede Woche von Hand machst. [→ ansehen](https://blaumilch.substack.com/p/die-chat-decke)
4. **Versionieren & Teilen.** Du sicherst deine Skill und teilst sie mit der Welt, ohne einen einzigen Befehl auswendig zu lernen. [→ ansehen](https://blaumilch.substack.com/p/die-chat-decke)
5. **Ein Vorgeschmack: Supabase.** Du hängst Claude an eine echte Datenbank und fragst sie in normalen Worten, kein SQL, kein Server. [→ ansehen](https://blaumilch.substack.com/p/die-chat-decke)
