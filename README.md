# blaumilch-agenten

Offene Werkstatt der **Blaumilch-Agenten**: Skills, Workflows und Prompts zum Mitnehmen. Wächst Stück für Stück.

## Inhalt

- **[claude-code-foundation/](claude-code-foundation/)**: der kostenlose Einsteiger-Kurs in fünf Modulen. Überblick, Links zu den Videos und zur Begleitseite.
- **[prompts/](prompts/)**: *Besser prompten*, die komplette Prompt-Sammlung (Grundausstattung, Frameworks, Techniken). Kostenlos, tool-agnostisch, auf Deutsch.
- **[ai-chief-of-staff/](ai-chief-of-staff/)**: das n8n-Baukasten-Set für einen eigenen AI Chief of Staff (Fireflies, Notion, Supabase). In Stufen aufgebaut, native n8n-Nodes, jede Node mit Sticky-Notes erklärt. Credentials nicht enthalten.
